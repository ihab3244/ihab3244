## 🚀 About Me

I build software that bridges physical hardware and web applications. Currently at **Megastore Technologie** in Algiers, working on end-to-end RFID systems across **HF, UHF, and 125kHz**—spanning reader integration, low-level hardware communication, robust backend APIs, and modern React interfaces.
